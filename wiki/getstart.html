PROJECT GUIDE / 01

Getting started with E-comOS

E-comOS is a microkernel operating system project focused on a practical, lightweight system for capable hardware. This guide introduces the project and points to its active repositories and documentation.

01 / APPROACH

Small by design

As a microkernel, E-comOS values a small core over an all-encompassing system. The project describes its model as: everything is a process, everything is an object, everything is a service.

The goal is to serve computers that remain useful, without burying core work under one-off compatibility code. The focus is on support that a small team can build and maintain sustainably.
